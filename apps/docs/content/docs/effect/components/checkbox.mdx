Use a checkbox for a choice someone can check or uncheck. Use a group when several choices belong to one value.

## Installation

```bash
npm install @ui-sdk/effect @ui-sdk/core
```

## Composition

`Checkbox` and `CheckboxGroup` are headless components. Their `view` gets these parts:

```text
Checkbox
├── checkbox.root
│   └── checkbox.indicator
└── checkbox.input

CheckboxGroup
├── group.group
├── group.input
└── group.join
```

Apply the root to a button and the indicator inside it. The indicator shows while the checkbox is checked or mixed. The input is the hidden native checkbox that takes part in forms: apply it to an `h.input` beside the button. Wrap all of it and the checkbox's text in a label.

## Usage

Call it in your view and apply its parts:

```ts
import * as Html from "@effect/ui/html/Html"
import { Checkbox } from "@ui-sdk/effect/checkbox"
import * as Schema from "effect/Schema"

const Example = Html.component({
  name: "Example",
  model: Schema.Null,
  message: Schema.Never,
}).make({
  init: () => null,
  update: ($) => $.model,
  view: (h) =>
    Checkbox(h, {
      view: (checkbox) =>
        h.label.children(
          checkbox
            .root(h.button)
            .children(
              checkbox.indicator(
                h.span.attr("aria-hidden", "true").children("✓")
              )
            ),
          checkbox.input(h.input),
          "Accept terms and conditions"
        ),
    }),
})

export { Example }
```

The indicator part returns `undefined` while it's out of the page, so give it its children before you apply it. A headless component's `view` returns one element, which is why the label wraps the button and its input.

## Indeterminate

An indeterminate checkbox represents a partly checked set. It has `aria-checked="mixed"` and `data-indeterminate`. A press checks it; only your code puts it back into the mixed state.

Start with `defaultChecked: "indeterminate"`, or pass `"indeterminate"` as the controlled value. The indicator's state tells it which icon to show. A [parent checkbox](#parent-checkbox) derives this state from a group for you.

```ts
Checkbox(h, {
  props: { defaultChecked: "indeterminate" },
  view: (checkbox) =>
    h.label.children(
      checkbox
        .root(h.button)
        .children(
          checkbox.indicator(
            h.span.children(
              checkbox.indicator.state().indeterminate ? Minus(h) : Check(h)
            )
          )
        ),
      checkbox.input(h.input),
      "Select all"
    ),
})
```

## Forms

Pass `name` and `value` to include a checked checkbox in a native form. Unchecked and mixed checkboxes submit nothing. The default value is `"on"`. Independent checkboxes can share a name to submit several values; use a [group](#group) when your app also needs one list of checked values.

`required` blocks submission until the checkbox is checked. Reset returns it to `defaultChecked`. Pass `form` with a form's id to join it from elsewhere on the page.

## Group

`CheckboxGroup` keeps one list of checked values. Each checkbox supplies its `value`, and joins the group by taking its `join` as `group`. The group returns selected values in the order the checkboxes appear. Name the group with `aria-label`, `aria-labelledby`, or a [Field](#group-in-a-form). Apply the group's `input` beside it.

```ts
CheckboxGroup(h, {
  props: { defaultValue: ["cheese"] },
  view: (toppings) =>
    h.div.children(
      toppings.group(h.div.attr("aria-label", "Toppings")).children(
        items.map((item) =>
          Checkbox(h, {
            key: item.value,
            props: { value: item.value, group: toppings.join },
            view: (checkbox) => topping(checkbox, item.label),
          })
        )
      ),
      toppings.input(h.input)
    ),
})
```

## Parent Checkbox

Add a checkbox with `parent: true` to check or uncheck the group. It is checked when every value is selected, unchecked when none are, and mixed in between. It points to its children with `aria-controls` and submits nothing itself.

Pass `allValues` to the group so the parent has the right state on the first render, including on the server. Otherwise it discovers the values after the checkboxes mount.

## Group in a Form

Pass `name` to the group to submit every checked value under that name. `required` requires at least one selection, and Reset restores `defaultValue`. The same `disabled` and `form` options apply as on a single checkbox.

In a field, apply the field's `control` to the group, `field.control(group.group(h.div))`. The field supplies the group's label and description, and its `error` shows the validation message inline until a selection makes the group valid. [Field](./field) covers the shared field behavior.

## Animation

The indicator has `data-starting-style` as it appears and `data-ending-style` while it leaves, and stays mounted until its exit finishes. Transition from those states:

```css
[data-slot="checkbox-indicator"] {
  transition:
    opacity 0.15s,
    scale 0.15s;

  &:is([data-starting-style], [data-ending-style]) {
    opacity: 0;
    scale: 0.5;
  }
}
```

`keepMounted` keeps the indicator in the page while unchecked, with `data-unchecked`, for styles that show both states.

## Styling

Use `data-checked`, `data-unchecked` and `data-indeterminate` for the checked state, and `data-disabled`, `data-readonly` and `data-required` for the rest. The indicator gets the same state attributes as its checkbox.

## Accessibility

The checkbox follows the [WAI-ARIA checkbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/), and a group's parent checkbox follows its [mixed checkbox example](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/examples/checkbox-mixed/). The root gives a button the `checkbox` role, and the input makes a hidden native checkbox that takes part in forms. Every line below is an automated test.

### Keyboard

| Key   | Does                                         |
| ----- | -------------------------------------------- |
| Tab   | Moves to the next checkbox                   |
| Space | Checks or unchecks it, or checks a mixed one |
| Enter | Submits its form                             |
