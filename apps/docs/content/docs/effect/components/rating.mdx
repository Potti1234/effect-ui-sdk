Use a rating to collect a score, like how a stay went, or to show one, like an average. Each star is a radio, so it works like a radio group, with one value and a single tab stop.

## Installation

```bash
npm install @ui-sdk/effect @ui-sdk/core
```

## Composition

`Rating` is a headless component. Its `view` gets these parts:

```text
Rating
├── rating.root
└── rating.item (index)
    ├── rating.radio (value)
    └── rating.input (value)
```

Render one `item` per star, with its `index` from 1 to `max` (5 by default). Inside each star, put your icon, then a `radio` and its hidden native `input` for each score the star picks. `ratingItemValues(index, step)` lists them: one per star, or two with `step: 0.5`. Give both the score as text.

## Usage

Call it in your view and apply its parts:

```ts
import * as Html from "@effect/ui/html/Html"
import { Rating, ratingItemValues } from "@ui-sdk/effect/rating"
import * as Schema from "effect/Schema"

const Example = Html.component({
  name: "Example",
  model: Schema.Null,
  message: Schema.Never,
}).make({
  init: () => null,
  update: ($) => $.model,
  view: (h) =>
    Rating(h, {
      props: { defaultValue: 3 },
      view: (rating) =>
        rating.root(h.div.attr("aria-label", "Rating")).children(
          [1, 2, 3, 4, 5].map((index) =>
            rating.item(h.span.key(String(index)), { index }).children(
              starIcon(h),
              ratingItemValues(index).flatMap((score) => [
                rating.radio(h.button.key(`radio-${score}`), {
                  value: String(score),
                }),
                rating.input(h.input.key(`input-${score}`), {
                  value: String(score),
                }),
              ])
            )
          )
        ),
    }),
})

export { Example }
```

Name the rating with `aria-label`, or put it in a [Field](./field) whose label names it, with `field.control(rating.root(h.div))`. Without `defaultValue`, nothing starts checked and Tab enters on the first star.

## Build Your Own

`@ui-sdk/effect/rating` comes with a ready-made Rating. If you'd like to build your own, with your own names, start from the `rating` primitive in `@ui-sdk/core`:

```ts title="score.ts"
import { rating } from "@ui-sdk/core/rating"
import { createParts } from "@ui-sdk/effect/primitive"

const Score = createParts(rating, {
  name: "Score",
  tags: { root: "div", item: "span", radio: "button", input: "input" },
})

export { Score }
```

Each part keeps the behavior, state and data attributes of its ready-made counterpart. See [Rendering](../rendering) and [Custom Parts](../custom-parts) for more.

## Stars

Put your icon in `rating.item`. Each item says how much of its star the shown score covers: `--rating-fill` goes from 0 to 1, `data-filled` marks a whole star and `data-partial` the star a score ends partway through. The radios that pick the score sit over the icon, so it needs no events of its own.

```css
[data-slot="rating-item"] {
  color: lightgray;
}

[data-slot="rating-item"][data-filled] {
  color: gold;
}
```

For half stars and averages, paint the icon up to `calc(var(--rating-fill) * 100%)`, like with a gradient behind a star-shaped mask.

Read a star's state with `rating.item.state({ index })` to render from it, like an icon that fills once the score covers the star:

```ts
const star = rating.item.state({ index })
h.el("svg")
  .attrs({
    viewBox: "0 0 24 24",
    fill: star.fill === 1 ? "currentColor" : "none",
    stroke: "currentColor",
    "stroke-width": "2",
    "aria-hidden": "true",
  })
  .children(h.el("path").attr("d", starPath))
```

## Half Stars

Set `step: 0.5` to split each star in two, and list each star's scores with `ratingItemValues(index, 0.5)`. Each half is its own radio, named like "2.5 stars", and a press on the first half of a star picks the half score.

## Preview

While a pointer moves over the stars, they show the score under it: `--rating-fill` follows the pointer, and `data-highlighted` marks the stars up to it. Leaving the stars shows the score again. Touch has no preview, since a tap picks the score at once.

## Deselectable

Set `deselectable` to let people clear their score: a press on the checked star, or Space on it, sets the score back to `null`.

## Read-Only

Set `readOnly` to show a score that can't change, like an average. Any score shows, like 4.2, which fills a fifth of the last star. The rating becomes one image for screen readers, and its radios are hidden from them.

Name a read-only rating with `getValueLabel`, so its name includes the score. An `aria-label` would replace it.

<ComponentExample

## Controlled

Keep `value` in your Model, pass it as a prop, and change it in `update` when `ValueChange` arrives. To refuse a change, leave the Model as it is. A [controller](#controller) from `createRatingController()` sets the score from anywhere, like the Clear Rating button below: call it from a Command. Create one controller per mounted rating.

## Form

Each `rating.input` is a hidden native radio, so the rating takes part in forms. Set `name` to submit the score; nothing submits without a name or a score. `required` blocks submission until there's a score, and a reset returns to `defaultValue`.

## Stars and Labels

Set `max` for the number of stars, and render that many items. `loop` lets the arrow keys wrap from the last star to the first. Each radio is named by `getValueLabel`, which gets the score and `max` and says "1 star" or "3 stars" by default.

```ts
Rating(h, {
  props: {
    max: 10,
    loop: true,
    getValueLabel: (value: number, max: number) => `${value} of ${max}`,
  },
  view: (rating) => ...,
})
```

## Accessibility

A rating is a radio group, so it follows the [WAI-ARIA radio group pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) and behaves like native radios that share a name. Each star holds a `rating.radio`, a button with the `radio` role, per score it can pick, and a `rating.input`, a hidden native radio that takes part in forms. Icons inside the stars should be hidden from screen readers with `aria-hidden`, since each radio is already named. A read-only rating has the `img` role instead, named by `getValueLabel`.

### Keyboard

| Key        | Does                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| Tab        | Moves into the rating, onto the checked star or the first one                              |
| Arrow keys | Move to the next or previous score and check it, stopping at the ends unless `loop` is set |
| Space      | Checks the focused star, or clears it when it's checked and `deselectable`                 |
| Enter      | Submits its form                                                                           |
