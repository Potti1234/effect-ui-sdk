<Callout>

These docs cover ui-sdk in Effect UI. Using another framework? See [React](/docs/react), [Vue](/docs/vue), [Svelte](/docs/svelte), [Solid](/docs/solid) or [Web Components](/docs/web-components). To build your own components from behaviors, see [Core](/docs/core).

</Callout>

`@ui-sdk/effect` gives you components such as Collapsible as Effect UI headless components, built on ui-sdk's behaviors. They handle interactions, focus, and ARIA attributes. You choose their markup and styles.

Each component is a headless component: call it in your view with `h`, apply its parts to your own elements, and handle its events in your `update`. Its state can live in your Model, so every change is a message you can log, replay and test.
