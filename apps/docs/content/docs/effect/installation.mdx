---
title: Installation
description: Install UI SDK in your Effect UI app.
---

Start with an app using Effect UI and Effect 4. Effect UI isn't on npm yet, so install it from a snapshot build, with the same commit for every Effect UI package:

```bash
npm install effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@<sha>
```

## Install the Packages

```bash
npm install @ui-sdk/effect @ui-sdk/core
```

`@ui-sdk/effect` provides the Effect UI components. `@ui-sdk/core` provides their behavior and is a peer dependency. Install both so the components and any helpers you use share one copy of the core.

With Vite, leave `@ui-sdk/core` out of dependency pre-bundling. Otherwise a core entry your app imports, like `@ui-sdk/core/collapsible`, is bundled apart from the copy `@ui-sdk/effect` loads:

```ts title="vite.config.ts"
import { defineConfig } from "vite"

export default defineConfig({
  optimizeDeps: { exclude: ["@ui-sdk/core"] },
})
```

## Import a Component

Import each component from its own entry:

```ts
import { Collapsible } from "@ui-sdk/effect/collapsible"
```

A component is one headless component, and its `view` gets every part, so there's nothing else to import. Each [component page](./components) lists its parts.

## Add Your Styles

Components are unstyled, so you style them with your app's CSS or with Tailwind CSS. Parts carry `data-slot` and state attributes like `data-open`, which your selectors can use.

For a default look to start from, import `@ui-sdk/core/web.css` once, at the top of your app's entry:

```ts
import "@ui-sdk/core/web.css"
```

You can render your first component without setting up a provider or adding a portal root. Parts render their attributes on the server with `HtmlServer`, and hydrate with `HtmlHydrate`.
