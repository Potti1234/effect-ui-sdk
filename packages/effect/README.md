# @ui-sdk/effect

UI SDK for Effect UI. A library of behaviors to build your components.

```bash
npm install @ui-sdk/effect @ui-sdk/core
```

It needs Effect 4 and `@effect/ui`, which ships as a snapshot build until it's on npm.

[Read the docs](https://ui-sdk.dev/docs/effect)

The docs also ship in this package as Markdown, starting at `docs/llms.txt`, for your editor and your agent.
